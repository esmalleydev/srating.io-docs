# [docs.srating.io](https://docs.srating.io)

This is the open-source API documentation site for [srating.io](https://srating.io). It is built with [Next.js](https://nextjs.org/), [React](https://reactjs.org/), [Fumadocs](https://fumadocs.dev/) and [Tailwind CSS](https://tailwindcss.com/), and the pages themselves are MDX.

Prerequisites: Node.js 20.9+, npm.

## Set up

After cloning project, in the project directory run:
`npm install`

To start developing run:
`npm run dev`

The dev server runs on [localhost:3001](http://localhost:3001), not the usual 3000.

To build and serve the production site:
```console
npm run build
npm start
```

`npm start` also listens on 3001, and it will not run until `npm run build` has been run at least once.

## Writing docs

Every page is an `.mdx` file under `content/`, and the folder layout is the URL. Pages are served from the site root rather than under `/docs`, so `content/game/get.mdx` becomes [docs.srating.io/game/get](https://docs.srating.io/game/get). That is set by `baseUrl` in `lib/source.ts`; the public URLs predate this site and are linked from srating.io, so leave it alone.

A resource is a folder: an `index.mdx` for the landing page, one `.mdx` per endpoint, and a `meta.json` giving the folder its sidebar title and ordering the pages.

```
content/
  meta.json          -- top level sidebar order, "---Label---" entries are group headers
  game/
    meta.json        -- { "title": "Games / Scores", "pages": ["index", "get", ...] }
    index.mdx
    get.mdx          -- docs.srating.io/game/get
    getGames.mdx
```

Each page starts with frontmatter:

```mdx
---
title: "get"
description: "This request will find the first matching row..."
---
```

Anything added to `content/` also has to be listed in the relevant `meta.json`, otherwise it will not appear in the sidebar.

May need to clear out .next folder before rebuilding
`rm -rf .next`

`.source/` is generated by fumadocs-mdx on dev/build. It is gitignored, and deleting it is safe.
