## Read transfer rows

Returns every matching row instead of just the first. See [get vs read](/get_vs_read) for details.

Drop `player_id` from a [get](/cbb_transfer_player_season/get) request to get every transfer for a season in one call.

### Request

GET

```console
https://api.srating.io/v1/cbb_transfer_player_season/read?season=2024
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'cbb_transfer_player_season',
    'function': 'read',
    'arguments': {
      'season': 2024,
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```
