## Read player boxscores

Returns every matching player boxscore with the sport-specific stats **already merged in**.

This is the bulk version of [getPlayerBoxscore](/player_boxscore/getPlayerBoxscore). Pass a `game_id` without a `player_id` and you get every player in that game — the usual way to pull a full stat sheet in one request.

### Access

This returns every matching row, so it needs a paid subscription with read access. Free trial keys get `access denied` — see [Usage tokens](/tokens).

Usage is billed by response size, and a game's worth of players is a large response, so filter as tightly as you can.

### Required arguments
`organization_id`

Everything else is a filter. `game_id` gets every player in a game; `player_id` with `season` gets one player's whole season.

### Request

GET

```console
https://api.srating.io/v1/player_boxscore/readPlayerBoxscore?organization_id=f1c37c98-3b4c-11ef-94bc-2a93761010b8&game_id=0f0fb2e7-5dd9-11ef-9222-9667e47de71a
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'player_boxscore',
    'function': 'readPlayerBoxscore',
    'arguments': {
      'organization_id': 'f1c37c98-3b4c-11ef-94bc-2a93761010b8',
      'game_id': '0f0fb2e7-5dd9-11ef-9222-9667e47de71a',
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```
