## Read player boxscore rows

Returns every matching row instead of just the first. See [get vs read](/get_vs_read) for details.

Drop `player_id` from a [getPlayerBoxscore](/player_boxscore/getPlayerBoxscore) request to get every player's boxscore for a game in one call.

### Request

GET

```console
https://api.srating.io/v1/player_boxscore/read?organization_id=f1c37c98-3b4c-11ef-94bc-2a93761010b8&game_id=0f0fb2e7-5dd9-11ef-9222-9667e47de71a
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'player_boxscore',
    'function': 'read',
    'arguments': {
      'organization_id': 'f1c37c98-3b4c-11ef-94bc-2a93761010b8',
      'game_id': '0f0fb2e7-5dd9-11ef-9222-9667e47de71a',
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```
