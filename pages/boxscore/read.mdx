## Read boxscore rows

Returns every matching row instead of just the first. See [get vs read](/get_vs_read) for details.

Drop `team_id` from a [getBoxscore](/boxscore/getBoxscore) request to get both teams' boxscores for a game in one call.

### Request

GET

```console
https://api.srating.io/v1/boxscore/read?organization_id=f1dedce6-3b4c-11ef-94bc-2a93761010b8&game_id=91897046-68e4-11ef-9222-9667e47de71a
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'boxscore',
    'function': 'read',
    'arguments': {
      'organization_id': 'f1dedce6-3b4c-11ef-94bc-2a93761010b8',
      'game_id': '91897046-68e4-11ef-9222-9667e47de71a',
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```
