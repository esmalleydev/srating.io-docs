## Read boxscores

Returns every matching team boxscore with the sport-specific stats **already merged in**.

This is the bulk version of [getBoxscore](/boxscore/getBoxscore), and it saves you a second request: a plain [read](/boxscore/read) on the `boxscore` table gives you a `sport_boxscore_id` that you'd then have to look up yourself. This does that join for you.

### Access

This returns every matching row, so it needs a paid subscription with read access. Free trial keys get `access denied` — see [Usage tokens](/tokens).

Usage is billed by response size, so filter as tightly as you can.

### Required arguments
`organization_id`

Everything else is a filter, and the more you add the smaller the response. `game_id` gets both teams in one game; adding `team_id` narrows it to one side. `season` with `team_id` gets a team's whole season.

### Request

GET

```console
https://api.srating.io/v1/boxscore/readBoxscore?organization_id=f1dedce6-3b4c-11ef-94bc-2a93761010b8&game_id=91897046-68e4-11ef-9222-9667e47de71a
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'boxscore',
    'function': 'readBoxscore',
    'arguments': {
      'organization_id': 'f1dedce6-3b4c-11ef-94bc-2a93761010b8',
      'game_id': '91897046-68e4-11ef-9222-9667e47de71a',
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```
