## Request / Response Headers

### Required Request Headers
```console
X-API-KEY
```
You must include your API key in the header under "X-API-KEY"

### Important Response Headers
```console
X-USAGE-REMAINING
X-USAGE-USED
X-REQUEST-USAGE
```
`X-USAGE-REMAINING` and `X-USAGE-USED` are your key's usage against its monthly usage limit, after this request. `X-REQUEST-USAGE` is what this specific request cost. This data can also be viewed in your account, in the subscription.

See [Usage tokens](/tokens) for how the cost of a request is calculated.

Usage resets on the 1st of each month.
