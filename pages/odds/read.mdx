## Read odds rows

Returns every matching row instead of just the first. See [get vs read](/get_vs_read) for details.

A game has more than one `odds` row over time as the line moves -- pass just `game_id` (no `odds_id`) to get all of them, current and historical.

### Request

GET

```console
https://api.srating.io/v1/odds/read?game_id=40fd1ac3-5dd9-11ef-9222-9667e47de71a
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'odds',
    'function': 'read',
    'arguments': {
      'game_id': '40fd1ac3-5dd9-11ef-9222-9667e47de71a',
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```
