## Get conference predictions

Returns projected final standings for a conference: every team's record with the remaining unplayed games already simulated using our per-game predictions.

The `wins`, `losses`, `confwins`, and `conflosses` on each row are **current record plus projected results** for every game still to play, so you get a season-end projection rather than today's standings.

### Access

Projections require an active paid subscription. On a free trial, or with no subscription, you still get each team's current stats but the remaining games are not simulated, and every row comes back with `hasAccess: false`.

### Required arguments
`organization_id`, `conference_id`, `season`

### Request

GET

```console
https://api.srating.io/v1/conference/getConferencePrediction?organization_id=f1c37c98-3b4c-11ef-94bc-2a93761010b8&conference_id=aaa5086f-1095-11ef-9686-72fab666226a&season=2026
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'conference',
    'function': 'getConferencePrediction',
    'arguments': {
      'organization_id': 'f1c37c98-3b4c-11ef-94bc-2a93761010b8',
      'conference_id': 'aaa5086f-1095-11ef-9686-72fab666226a',
      'season': 2026,
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```

Response

Keyed by `statistic_ranking_id`, one entry per team in the conference. Stat columns are trimmed here — each row carries the full set shown on [team/getStats](/team/getStats).

```json
{
  "53fb68bb-e9e2-11ed-9185-b6be2f39279c": {
    "statistic_ranking_id": "53fb68bb-e9e2-11ed-9185-b6be2f39279c",
    "team_id": "87019264-8549-11ed-bf01-5296e1552828",
    "season": 2026,
    "wins": 29,
    "losses": 6,
    "confwins": 15,
    "conflosses": 5,
    "streak": 3,
    "offensive_rating": 112.48,
    "defensive_rating": 95.67,
    "adjusted_efficiency_rating": 20.54,
    "date_of_rank": "2026-04-05T04:00:00.000Z",
    "current": 1,
    "deleted": 0,
    "hasAccess": true
  }
}
```

Sort the rows by `confwins` to get the projected conference table.
