## Read coach rows

Returns every matching row instead of just the first. See [get vs read](/get_vs_read) for details. Most filter arguments also accept an array of values, matched with an `OR`.

### Request

GET

```console
https://api.srating.io/v1/coach/read?coach_id=cf3f6a9d-0fe0-11ef-9686-72fab666226a&coach_id=d21f4a10-0fe0-11ef-9686-72fab666226a
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'coach',
    'function': 'read',
    'arguments': {
      'coach_id': [
        'cf3f6a9d-0fe0-11ef-9686-72fab666226a',
        'd21f4a10-0fe0-11ef-9686-72fab666226a',
      ],
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```
