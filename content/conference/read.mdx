---
Returns every matching row instead of just the first. See [get vs read](/get_vs_read) for details.

### Request

GET

```console
https://api.srating.io/v1/conference/read?inactive=0
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'conference',
    'function': 'read',
    'arguments': {
      'inactive': '0',
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```
