---
title: "read"
description: "Returns every matching row instead of just the first."
---
Returns every matching row instead of just the first. See [get vs read](/get_vs_read) for details. Most filter arguments also accept an array of values, matched with an `OR`.

### Request

GET

```console
https://api.srating.io/v1/game/read?game_id=40fd1ac3-5dd9-11ef-9222-9667e47de71a&game_id=41128f5e-5dd9-11ef-9222-9667e47de71a
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'game',
    'function': 'read',
    'arguments': {
      'game_id': [
        '40fd1ac3-5dd9-11ef-9222-9667e47de71a',
        '41128f5e-5dd9-11ef-9222-9667e47de71a',
      ],
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```
