---
title: "getStats"
description: "Returns the stats both teams had going into a specific game — not their end-of-season numbers."
---
Returns the stats both teams had **going into** a specific game — not their end-of-season numbers.

Rankings are stored once per day, if there were games the day before and this picks the most recent row for each team dated on or before the game. Nothing calculated after the game is used, which is what you want when backtesting a model: it's the information that was actually available at tip-off.

### Required arguments
`game_id`

That's it — the sport, division, season, and both teams are read off the game.

### Request

GET

```console
https://api.srating.io/v1/game/getStats?game_id=40fd1ac3-5dd9-11ef-9222-9667e47de71a
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'game',
    'function': 'getStats',
    'arguments': {
      'game_id': '40fd1ac3-5dd9-11ef-9222-9667e47de71a',
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```

Response

Keyed by `team_id` — the home team and the away team. Stat columns are trimmed here for readability; each row carries the full set shown on [team/getStats](/team/getStats).
