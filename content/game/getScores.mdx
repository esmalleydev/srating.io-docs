A lighter-weight version of [getGames](/game/getGames) — returns just the score, status, clock and pre-game prediction for each game, without the full game, team or odds objects.

### Required arguments
Must specify a organization_id, division_id and (start_date or a season with a home/away_team_id)

`start_date` (YYYY-MM-DD)

OR

`season` AND (`home_team_id` OR `away_team_id`)

### Request

GET

```console
https://api.srating.io/v1/game/getScores?start_date=2023-04-03&organization_id=f1c37c98-3b4c-11ef-94bc-2a93761010b8&division_id=bf602dc4-3b4a-11ef-94bc-2a93761010b8
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'game',
    'function': 'getScores',
    'arguments': {
      'start_date': '2023-04-03',
      'organization_id': 'f1c37c98-3b4c-11ef-94bc-2a93761010b8',
      'division_id': 'bf602dc4-3b4a-11ef-94bc-2a93761010b8',
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```
