Returns our model's prediction for every game on a team's schedule in a season — win probability and projected score for both sides.

This covers the whole schedule in one request, played and unplayed. For games already final you can compare the prediction against the real result in [game/get](/game/get).

### Access

Prediction values require an active paid subscription. On a free trial, or with no subscription, the rows still come back but `home_percentage`, `away_percentage`, `home_score`, and `away_score` are all `null`.

### Required arguments
`organization_id`, `division_id`, `team_id`, `season`

### Request

GET

```console
https://api.srating.io/v1/team/getSchedulePredictions?organization_id=f1c37c98-3b4c-11ef-94bc-2a93761010b8&division_id=bf602dc4-3b4a-11ef-94bc-2a93761010b8&team_id=87019264-8549-11ed-bf01-5296e1552828&season=2026
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'team',
    'function': 'getSchedulePredictions',
    'arguments': {
      'organization_id': 'f1c37c98-3b4c-11ef-94bc-2a93761010b8',
      'division_id': 'bf602dc4-3b4a-11ef-94bc-2a93761010b8',
      'team_id': '87019264-8549-11ed-bf01-5296e1552828',
      'season': 2026,
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```

Response

Keyed by `prediction_id`, one entry per game on the schedule.

```json
{
  "6b1f9a24-0c3d-11ef-9686-72fab666226a": {
    "prediction_id": "6b1f9a24-0c3d-11ef-9686-72fab666226a",
    "game_id": "40fd1ac3-5dd9-11ef-9222-9667e47de71a",
    "season": 2026,
    "home_percentage": 0.7412,
    "away_percentage": 0.2588,
    "home_score": 74,
    "away_score": 68,
    "live": 0,
    "current": 1,
    "date_of_entry": "2026-04-03T08:00:00.000Z",
    "guid": "9c2d4e6f-8a1b-4c3d-9e5f-7a8b9c0d1e2f",
    "deleted": 0
  }
}
```

`home_percentage` and `away_percentage` are win probabilities that sum to 1. `home_score` and `away_score` are the projected final score. Use `game_id` to join back to the game itself.

Only pre-game predictions are returned here (`live` is always `0`).
