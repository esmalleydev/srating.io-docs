---
title: "read"
description: "Returns every matching row instead of just the first."
---
Returns every matching row instead of just the first. See [get vs read](/get_vs_read) for details. Most filter arguments also accept an array of values, matched with an `OR`.

### Request

GET

```console
https://api.srating.io/v1/player/read?player_id=dff6dce2-ad5a-11ed-9185-b6be2f39279c&player_id=e27545f0-ad5a-11ed-9185-b6be2f39279c
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'player',
    'function': 'read',
    'arguments': {
      'player_id': [
        'dff6dce2-ad5a-11ed-9185-b6be2f39279c',
        'e27545f0-ad5a-11ed-9185-b6be2f39279c',
      ],
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```
