title: "read"
description: "Returns every matching row instead of just the first."
---
Returns every matching row instead of just the first. See [get vs read](/get_vs_read) for details.

Drop `team_id` from a [get](/elo/get) request to get every team's current elo for a season in one call.

### Request

GET

```console
https://api.srating.io/v1/elo/read?organization_id=f1c37c98-3b4c-11ef-94bc-2a93761010b8&division_id=bf602dc4-3b4a-11ef-94bc-2a93761010b8&season=2023&current=1
```

POST
```js {5} copy filename="javascript"
fetch('https://api.srating.io/v1', {
  'method': 'POST',
  'headers': {
    'Content-Type': 'application/json',
    'X-API-KEY': 'YOUR_API_KEY',
  },
  'body': JSON.stringify({
    'class': 'elo',
    'function': 'read',
    'arguments': {
      'organization_id': 'f1c37c98-3b4c-11ef-94bc-2a93761010b8',
      'division_id': 'bf602dc4-3b4a-11ef-94bc-2a93761010b8',
      'season': 2023,
      'current': 1,
    }
  }),
}).then(response => {
  return response.json();
}).then(json => {
  console.log(json);
  return json;
}).catch(error => {
  console.log(error);
});
```
